
# Practice 09 - Game Development with Pygame

This project contains three Python applications developed using Pygame.

## 1. Mickey's Clock
- Displays the current minutes and seconds.
- Updates automatically every second.
- Uses rotation and angles to draw clock hands.

Run:
```bash
cd mickeys_clock
python main.py
```

## 2. Music Player
- Plays MP3 and WAV audio files.
- P - Play
- S - Stop
- N - Next track
- B - Previous track
- Q - Quit
- Displays track information and playback progress.

Place audio files in `music_player/music/sample_tracks/`.

Run:
```bash
cd music_player
python main.py
```

## 3. Moving Ball
- Displays a red ball on a white background.
- Arrow keys move the ball by 20 pixels.
- The ball stays inside the screen.

Run:
```bash
cd moving_ball
python main.py
```

## Requirements
- Python 3
- Pygame
- Mutagen

Install dependencies:
```bash
pip install -r requirements.txt
```
